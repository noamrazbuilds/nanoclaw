## Behavioral spec (one paragraph)
When the container is shutting down (SIGTERM from Docker, clean exit from the agent's poll loop, OR a `PreCompact` hook from the SDK signaling context compaction), the agent-runner archives the current session's transcript as a human-readable Markdown file under `/workspace/group/conversations/`. The .jsonl SDK transcript is parsed into messages (`parseTranscript()`), rendered as Markdown (chat-history-style, role-prefixed), and written to `<date>-<name>.md` (where `<name>` is either a generated descriptive name for clean exits OR `incomplete-session` for SIGTERM/crash exits). Dedup: skip if any `.md` file under `conversations/` was written in the last 5 minutes (PreCompact hook would have archived; no need to duplicate). The reason: the SDK's `.jsonl` is machine-readable but not human-friendly; the Markdown archive lets the user (or the agent itself in a future session) skim past conversations as natural-language transcripts. SIGTERM-time archiving specifically catches the "Docker killed the container without warning" case where the SDK's PreCompact hook never fires.
